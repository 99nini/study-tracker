# Study Tracker

A command-line study tracker built with Python.

## Features

- Add study sessions
- Automatically record the date
- View saved sessions
- Calculate total study time
- Delete sessions
- Save data locally in JSON
- Validate user input

## Requirements

- Python 3.11 or newer

## Run the application

Open a terminal in the project folder and run:

`python study_tracker.py`

## Data storage

Study sessions are stored locally in `sessions.json`.

This file is ignored by Git, so personal study data is not uploaded to GitHub.
